Algebra

Formulae

1. (a + b)2 = a2 + 2ab + b2
2. (a - b)2 = a2 -2ab + b2
3. (a2 - b2) = (a - b)(a + b)
4. (a + b)3 = a3 + 3a2b + 3ab2 + b3
5. (a - b)3 = a3 - 3a2b + 3ab2 - b3

Mensuration

Formulae

1. Area of square = (side)2
2. Area of rectangle = (l * b)
3. Perimeter of square = 4 * side
4. Perimeter of rectangle = 2(l + b)
5. Volume of a cube = (side)3
6. Area of circle = π(radius)2

Geometry

Formulae

1. Pythagoras Theorem : (height)2 + (base)2 = (hypotenuse)2
2. Sum of all angles of a triangle = 180°
3. Sum of all angles of a quadrilateral = 360°
4. Sum of all angles for an n sided polygon = (n-2) * 180°
5. Each interior angle = {(n-2) * 180°}/n
