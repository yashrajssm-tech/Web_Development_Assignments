Some General terms

RAM
RAM is the laptop's temporary memory. More RAM helps you run multiple programs smoothly.
SSD
SSD is storage that saves your files, apps, and operating system. It makes the laptop start and load programs quickly.
CPU
CPU is the main processor that performs calculations and runs programs.
GPU
GPU handles graphics and is especially important for gaming, video editing, and 3D applications.
Refresh Rate
Refresh rate is how many times the screen updates per second, measured in Hz. A higher rate makes motion look smoother.
Battery Capacity
Battery capacity indicates how much energy the battery can store, usually measured in Wh (watt-hours).
