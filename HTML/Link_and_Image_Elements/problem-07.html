Python Programming Course

Master Python programming and build a strong foundation for software development, data science and automation!

1. Course Overview

This Python Programming course is designed for students and beginners who want to learn programming from the basics. The course starts with fundamental programming concepts and gradually introduces more advanced Python topics.
Through practical examples and programming exercises, students will learn how to write Python programs, solve problems and develop logical thinking skills. The course is suitable for students preparing for academic projects, coding competitions and entry-level programming roles.

View Python Course Reference and Syllabus

2. What You Will Learn

During this course, students will learn the essential concepts required to become confident Python programmers.


Introduction to Python programming
Variables and data types
Operators and expressions
Conditional statements
Loops and iteration
Functions
Lists, tuples, sets and dictionaries
File handling
Exception handling
Object-oriented programming basics
Problem-solving using Python

Course benefit: By completing the course, students will be able to create their own Python programs and apply programming concepts to practical problems.

3. Course Duration

Duration: 8 Weeks
Classes: 3 days per week
Class Duration: 1.5 hours per session
Mode: Online
Each week contains lessons, practical coding exercises and assignments. Students are encouraged to practise programming regularly outside the scheduled classes.
