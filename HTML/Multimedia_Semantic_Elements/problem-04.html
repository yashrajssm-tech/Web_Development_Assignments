Course Objectives

This course introduces the fundamentals of web development, focusing on HTML, CSS, and JavaScript.

Learning Outcomes

  • Understand HTML structure & semantic elements
  • Apply CSS for styling and layouts
  • Use JavaScript for interactivity
  • Build responsive web pages
  • Develop accessible and standards‑compliant sites
